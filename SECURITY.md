# Security policy

## Reporting a problem

If you find a security problem in this repository, such as a script that could do more than it says, a committed secret, or a template that would leave something unsafe, please report it privately.

1. Use the **Report a vulnerability** button on the repository's Security tab if it is shown.
2. If it is not shown, open an issue titled "Security contact request" with no technical detail in it, and a private route will be arranged.

Please do not post tokens, tenant identifiers, personal data or exploit detail in a public issue.

## What to expect

Reports are read as time allows. This is a personal portfolio project, not a supported product, so there is no service level. Confirmed problems are fixed in the next change and noted in the commit message.

## Scope

All example data in this repository is fictional. There are no real credentials, tenants or customer records here, and none should be added. See [CONTRIBUTING.md](CONTRIBUTING.md) for the ground rules.

# Changelog

All notable changes to this project are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Community health files: security policy, code of conduct, issue forms and a pull request template.
- Citation metadata (`CITATION.cff`) so the repository can be cited from GitHub.
- Dependabot configuration for GitHub Actions.

### Changed

- Minimum Python is now 3.10. Python 3.9 reached end of life in October 2025 and the current `actions/setup-python` no longer installs it, so CI could not test it.
- Replaced a broken ICO link about the IDTA and the UK Addendum with the current ICO page.


## [1.0.0] - 2026-11-11

### Added

- First public release: vendor-neutral reference architecture for keeping control of identity, data, AI and integration: layers, decision records, maturity model.
- See the README for scope, what has and has not been verified, and the roadmap.

# Code of conduct

This repository is a small, practical project. Anyone taking part in issues, pull requests or discussions is asked to:

- be courteous and assume good intent;
- keep feedback specific, and about the work rather than the person;
- accept that the maintainer decides what is merged, and why;
- never post personal data, credentials or confidential material from any organisation.

Comments that are abusive, discriminatory or harassing will be removed, and repeat offenders may be blocked. To raise a concern about behaviour, open an issue titled "Conduct concern" without detail and a private route will be arranged.
